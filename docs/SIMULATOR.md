# 欢愉四人队 · 完美轴伤害模拟器

队伍：**银狼LV.999（1506） + 火花（1501） + 真珠（1503） + 星神★阿哈（1511）**
数据来源：hsr.nanoka.cc 4.6.51（技能倍率、行迹、星魂全部取自抓取数据，并有自动化一致性测试回查）

## 一、三种用法

| 方式 | 文件 | 说明 |
|---|---|---|
| **① 交互界面（推荐）** | `dist/hsr-team-sim.html` | 双击用浏览器打开即可。左侧 5 组参数卡（全局 + 4 角色）可拖动滑块/输入数值，任何改动 300ms 后自动重跑，右侧实时显示总伤害、DPS、角色占比、伤害类型拆分、行动时间轴、资源曲线。零依赖、可离线、file:// 直接可用。 |
| **② 命令行** | `dist/hsr-sim.mjs`（单文件）或 `bin/hsr-sim.mjs` | `node dist/hsr-sim.mjs`；支持 `--cycles`、`--set`、`--eidolon`、`--json`、`--timeline` |
| **③ 双击跑命令行** | `run-sim.command` | macOS 双击即运行命令行版并停留显示结果 |

常用命令：

    node dist/hsr-sim.mjs                                  # 默认（3 轮 / 350 行动值）
    node dist/hsr-sim.mjs --cycles 5                       # 5 轮
    node dist/hsr-sim.mjs --eidolon 6                      # 全员 6 星魂
    node dist/hsr-sim.mjs --set characters.1506.stats.spd=160
    node dist/hsr-sim.mjs --set options.infiniteSkillPoints=true
    node dist/hsr-sim.mjs --timeline                       # 打印完整行动轴
    node dist/hsr-sim.mjs --json --out result.json         # 导出完整结果（含每段伤害与乘区来源）
    npm test                                               # 全部测试（76 项）

修改参数后重新打包（改了 engine/ 或 ui/ 之后）：

    node scripts/build-ui.mjs        # 重新生成 dist/ 三个文件

## 二、伤害模型

### 欢愉伤害（本队 86% 的输出）

    欢愉伤害 = 倍率
             × 7535.107                 （80 级固定基础值）
             × (1 + 欢愉度)
             × (1 + 笑点 × 5 / (笑点 + 240))
             × 暴击区                    （必定暴击 = 1 + 暴伤；期望 = 1 + 暴击率 × 暴伤）
             × 易伤区                    （同类加算）
             × 抗性区                    （1 - 抗性 + 减抗/穿透）
             × 韧性减伤区                （未击破 10% 减伤）
             × 防御区                    （(200+攻方等级×10) / [(200+攻方等级×10) + (200+受方等级×10) × (1-减防-无视防御)]）
             × (1 + 增笑)

**关键结论：欢愉伤害不吃攻击力、生命值与「伤害提高」类增伤**，所以本队配装与拐位收益集中在欢愉度、笑点、暴击/暴伤、减防、穿透、易伤上。

该公式已用公开的实测样例做回归测试（0.2 倍率 / 120% 欢愉度 / 2 笑点 / 127.4% 暴伤 / 26% 易伤 / 20% 抗性 / 10% 韧性减伤 / 80 级打 76 级 = 3633.83），见 `tests/formula.test.mjs`，误差 < 1。

### 常规伤害

    常规伤害 = 缩放值（攻击力或防御力）× 倍率 × (1+增伤) × 暴击区 × 易伤区 × 抗性区 × 韧性区 × 防御区

银狼/火花的常规伤害吃攻击力，真珠的普攻与强化普攻吃**防御力**。

### 真实伤害

按参考伤害的比例结算，不再乘任何其他乘区（银狼盲盒的 20%、阿哈欢愉技的 20%/25%）。

## 三、完美轴是怎么跑的

模拟以**行动值（AV）**为时间轴，1 回合 = 10000 / 速度；每个角色按下面的优先级决策，阿哈时刻是独立的行动单位。

| 角色 | 行动优先级（完美轴） |
|---|---|
| 银狼LV.999 | 无敌玩家状态中 → 强化普攻（打完 3 次退出并清空隐藏分，星魂 1 保留 20%）；隐藏分 ≥ 60 → 终结技（进入结界 + 行动提前 100% + 20 隐藏分）；否则战技（+5 笑点并同源 +5 隐藏分）；战技点不足 → 普攻 |
| 火花 | 能量满 → 终结技（2 笑点 + 按欢愉度加成的全体伤害 + 天赋欢愉伤害）；连线中 → 把战技点尽可能换成互动陷阱（每次 +25%/+12.5% 与礼物）再强化普攻；否则战技开连线 |
| 真珠 | 深度学习充能 > 0 → 强化普攻（140% 防御全体 + 治疗 + 0.2 欢愉伤害）；能量满 180 → 终结技（+20 好活当赏、3 充能、指定美学底本、按欢愉人数行动提前/额外回合）；好活当赏未满 → 战技；否则普攻攒点 |
| 星神★阿哈 | 愿力满 8 → 终结技（240% 全体 + 5×72%，获得欢愉万相→全队命途升格）；否则战技（挂令使 + 62.5% 追加攻击，令使持有者每回合回 1 愿力）；战技点不足 → 普攻 |
| 阿哈时刻 | 速度 = 阿哈自身速度（专属机制「阿哈时刻在」）+ 队伍速度贡献；行动时全队依次施放欢愉技，随后把**本次计入的笑点等量转成全体好活当赏**，并**清空全部笑点** |

资源系统全部建模：战技点、笑点（全队共享）、好活当赏（2 回合 / 真珠无限且上限 50）、银狼隐藏分、阿哈愿力与欢愉万相、真珠深度学习充能、爆点、火花连线与陷阱层数。

## 四、可调参数（UI 与 CLI 同一套）

**全局**：轮数、敌人等级、弱点/基础抗性、额外减抗、易伤、韧性减伤、是否击破、敌人数量、初始/上限战技点、初始笑点、必定暴击、无限战技点、是否计入秘技、盲盒结算方式（理想/期望）、是否计入真伤、欢愉技是否同时吃笑点与好活当赏、欢愉伤害基础值、笑点乘区系数 k 与常数 c、阿哈时刻速度构成。

**每个角色**：启用开关、等级、**星魂解锁等级（0–6，带每级效果摘要）**、**专属光锥开关与叠影 1–5**、攻击力、防御力、生命值、速度、暴击率、暴击伤害、欢愉度、**各技能基础等级**、是否使用秘技进场、循环策略；阿哈可指定令使目标；火花可设置每次连线的陷阱上限。

面板默认值 = 站点满级基础值 + 行迹属性节点（**裸装**），请按你的实际面板修改后再看结果。

## 五、建模假设与已知限制

1. 欢愉伤害公式中的**笑点乘区**采用公开拆解的 1 + 笑点×5/(笑点+240)；系数 k、c 可在界面里调。
2. 好活当赏层数 = 阿哈时刻计入的笑点；**欢愉技同时吃好活当赏与当前笑点**（可关闭）。真珠的抵御值消耗不影响层数（官方数据未说明二者是否同池），按不衰减处理。
3. 理想轴假设：必定暴击、盲盒按"每次消耗战技点都触发"结算（可切到期望值模式）、礼物取主流选项（红红火火）。
4. 单目标环境；群攻技能按每个目标结算，由全体均分的技能按总量计。
5. **未建模**：治疗量与生存、欢愉负债的逐次结算、击破流程与削韧、敌方行动、**遗器套装效果**（请把遗器面板数值填进角色属性）、以及除专属光锥以外的其它光锥（见第九节）。
6. 星魂 0 默认；全员满魂（E6）会把 3 轮总伤害从约 77.8 万推到约 590.6 万，主要来自银狼 6 魂的全队减抗、火花 6 魂的额外伤害次数翻倍、真珠 6 魂的 240% 追加欢愉伤害与阿哈 6 魂的额外阿哈时刻，属机制叠加而非重复计算。
7. 星魂 3/5 只影响技能等级（已按数据表逐级缩放倍率）；其余星魂按上表实现，未实现的纯生存类效果（真珠 1 魂免死、抵御值相关）不计入伤害。

## 八、星魂机制与技能等级（v1.1.0 新增）

### 8.1 星魂解锁等级

每个角色都有 **0–6 魂**的下拉选择器（选项标签直接写出该级效果摘要）；界面里同时给出该角色的**星魂列表**，逐条显示名称、站点原文效果、类型（机制 / 技能等级）以及当前是否已解锁。参数与结果都会随选择实时刷新。

### 8.2 星魂对技能等级的影响（3 魂 / 5 魂）

技能等级 = **基础等级 + 星魂加成**，并受上限约束（普攻 10，其余 15）：

| 角色 | 3 魂 | 5 魂 |
|---|---|---|
| 银狼LV.999（1506） | 战技+2、普攻+1、欢愉技+1 | 终结技+2、天赋+2、欢愉技+1 |
| 火花（1501） | 战技+2、普攻+1、欢愉技+1 | 终结技+2、天赋+2、欢愉技+1 |
| 真珠（1503） | **终结技**+2、普攻+1、欢愉技+1 | **战技**+2、天赋+2、欢愉技+1 |
| 星神★阿哈（1511） | **终结技**+2、普攻+1、欢愉技+1 | **战技**+2、天赋+2、欢愉技+1 |

注意四人的 +2 技能并不相同（真珠与阿哈的 3 魂加的是终结技）。基础等级默认取行迹节点上限：**普攻 6、战技/终结技/天赋/欢愉技 10**；因此 0 魂时战技实际是 10 级（倍率 1.6），满魂后 12 级（1.76），数据表上限 15 级（2.0）。引擎按「实际等级 → 数据表参数」缩放 kit 数值，所以调低等级会真实降低倍率。

界面上每个角色卡片里都能单独调整**基础等级**（不填则用行迹上限），3/5 魂的加成在其上叠加。

## 九、专属光锥（v1.2.0 新增）

### 9.1 默认行为

四个角色**默认都装备各自的专属光锥（叠影 1）**，可在角色卡片的光锥区块里开关装备、切换叠影 1–5。光锥提供两部分收益：

1. **固定属性**（满级 80 级）自动并入角色面板：攻击力 / 生命值 / 防御力按「先加固定值、再乘百分比」结算，速度按百分比或固定值加成，且会同步影响出手频率与阿哈时刻速度；
2. **被动机制**按下表参与伤害与资源结算（参数随叠影变化）。

| 角色 | 专属光锥 | 被动 | S1 效果 | 引擎实现 |
|---|---|---|---|---|
| 银狼LV.999 | 欢迎来到银河城 | 稳赢 | 速度 +18%；欢愉伤害无视目标 20% 防御；对自身施放终结技时 +20 笑点（可触发 1 次，3 次普攻后重置） | 速度乘算进面板与阿哈时刻速度；自身无视防御；终结技触发笑点并计数重置 |
| 火花 | 花花世界迷人眼 | 瞩目 | 暴伤 +48%；队伍每有 1 名「欢愉」角色战技点上限 +1（最多 +3）；每消耗 1 战技点使自身无视防御 +5%（最多 4 层）；单回合消耗 ≥4 点获得【推流】，我方全体欢愉度 +20% | 全部实现（【推流】按持续 2 回合处理） |
| 真珠 | 献给明日的色彩 | 挥墨 | 防御力 +48%；对我方全体施放欢愉技时，敌方全体受到的伤害 +22%（3 回合）并固定回复 10 点能量 | 全部实现（易伤为全队共享乘区） |
| 星神★阿哈 | 当第一声「阿哈」响起 | 即兴巡演 | 基础速度 +12；对我方其他单体施放战技时 +10 笑点（每 2 回合 1 次），随后使我方全体无视敌方 16% 防御（整场，不叠加） | 全部实现（速度计入阿哈时刻速度） |

### 9.3 说明

- 只想看角色本体强度时，关掉对应角色的光锥开关即可；面板数值仍可手动填写（例如替换成别的光锥）。
- **其它光锥未建模**：界面只提供「专属光锥 / 不带光锥」两种选择，其他光锥请把它的面板数值填进角色属性里近似。
- 期望值口径：盲盒默认按游戏内概率衰减结算（expected 模式），互动陷阱的礼物按 50/50 期望（期望 +1 笑点 +1 战技点）结算，因此火花的陷阱循环在期望上可持续；把盲盒切到「理论上限」可查看纯上限值。
