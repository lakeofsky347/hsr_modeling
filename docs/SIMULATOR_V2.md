# 星穹铁道 · 通用队伍伤害模拟器 V2 使用说明

数据：hsr.nanoka.cc（CDN https://static.nanoka.cc/hsr/4.6.51）全量抓取：99 名角色、172 件光锥、64 套遗器、2779 个敌人。
技能倍率、能量、战技点、削韧、行迹、星魂、光锥叠影、遗器套装、敌人抗性/弱点/韧性都**从数据自动解析**；13 名角色另有手写机制。

## 一、使用

| 方式 | 说明 |
|---|---|
| [dist/hsr-sim-v2.html](../dist/hsr-sim-v2.html) | 双击打开（file:// 离线可用）。改参数后自动重算（Web Worker，一般 < 50 ms） |
| [dist/hsr-sim-v2.mjs](../dist/hsr-sim-v2.mjs) | 单文件 CLI，只需 Node ≥ 18 |

界面：
- **队伍**：4 个槽位（可留空）。角色可按名称/属性/命途/星级搜索；可设星魂 E0–6、技能等级、光锥与叠影、隧洞 4 件 + 位面 2 件、四个主词条、12 种副词条的有效词条数。
- **自定义面板**：显示计算出的面板，任一项填值即覆盖最终面板（用于直接录入游戏内面板）。
- **效果开关**：列出技能/行迹/星魂/光锥/遗器自动解析出的全部增益减益，标出“条件 / 低置信 / 未解锁”，可逐条关闭。
- **额外 Buff**：自行添加外部增益（属性、数值、目标、持续回合）。
- **敌人**：从敌人库选择，或自定义等级、数量 1–5、生命、韧性、弱点、7 属性抗性、速度、额外减防/易伤/减抗、始终击破/允许击破。
- **战斗设置**：轮数、首轮/每轮行动值、初始/上限战技点、初始能量、期望暴击 / 必定暴击、搜索宽度、笑点、忽略条件效果。
- **结果**：总伤害、每轮伤害、每行动值伤害、角色占比、伤害类型、自动排轴序列（A 普攻 / E 战技 / Q 终结技 / F 追加攻击 / A+ E+ 强化 / X 欢愉技 / M 忆灵），以及可展开到每段伤害与生效 Buff 的完整时间轴。
- 配置可导入/导出 JSON（与 CLI 的 `--config` 同格式），本地保存预设。

CLI 示例：

    node dist/hsr-sim-v2.mjs --team 1005,1307,1303,1217 --enemy 1005010 --cycles 5
    node dist/hsr-sim-v2.mjs --set team.0.eidolon=6 --set options.critMode=always --timeline
    node dist/hsr-sim-v2.mjs --list-characters 流萤      # 查角色 id
    node dist/hsr-sim-v2.mjs --list-monsters 可可利亚    # 查敌人 id
    node dist/hsr-sim-v2.mjs --print-config > my.json   # 导出配置，修改后 --config my.json

## 二、模型

- **面板**：80 级角色 + 光锥基础属性 → 行迹属性 → 遗器主词条（5★+15）+ 副词条（有效词条数 × 5★ 中档值，如暴击 2.916%、速度 2.3）→ 2 件套和常驻无条件效果 → 用户覆盖。速度% 只乘角色白值（光锥无速度）。
- **伤害**：常规伤害 = 倍率 × 面板 × (1+增伤) × 暴击区 × (1+易伤) × 抗性区 × 韧性区 × 防御区；抗性区按有效抗性 [-100%, 90%] 截断（乘区 0.1～2）；持续伤害不暴击；另有击破、超击破、真实伤害、欢愉伤害。逐项依据与手算见 `tests/v2/math.test.mjs`。
- **时间轴**：行动值（AV）轴，敌人在轴上（结算 DoT、击破恢复）；战技点、能量（回能一律 ×(1+能量恢复效率)，「固定恢复」除外）、行动提前、额外回合、Buff 回合数与层数都有模拟；描述为「<施放者>每回合开始时持续回合数减1」的 Buff 在施放者回合开始时递减。
- **自动排轴**：每个角色回合是一个决策点（普攻 / 战技 / 强化动作 × 是否插入终结技），用 beam search 搜索整场伤害最大的序列，并与“纯战技”“纯普攻”基线比较，保证不劣于两者。
- **理想化**：条件效果默认视为满足（可一键关闭），概率效果按期望，敌人不攻击。

## 三、覆盖程度

- **手写机制（13 名）**：银狼LV.999、火花、真珠、星神★阿哈（欢愉四人，移植 v1 完美轴）；流萤、丹恒•饮月、镜流、黄泉、刃、黑天鹅、花火、知更鸟、阮•梅；另有希儿、卡芙卡的小修正。
- **其余角色**：按数据自动解析。解析统计：角色伤害段 545 条（低置信 79）、角色效果 762 条（低置信 136）、光锥效果 354 条、遗器效果 144 条，详见 [data/v2/PARSE_REPORT.md](../data/v2/PARSE_REPORT.md)。
- 自动解析角色的**强化普攻/强化战技/欢愉技不会自动使用**（界面会给出警告），需要手写 override（写法见 [engine2/OVERRIDE_API.md](../engine2/OVERRIDE_API.md)）。

## 四、已知局限

- 不模拟敌人攻击、受击回能、击杀、护盾/治疗收益；多个敌人共用一条韧性。
- 追加攻击默认每个自身回合 1 次（`policy.fuaPerTurn` 可调）；忆灵随主角色回合出手。卡芙卡天赋本应由“队友普攻”触发并附加触电，目前按每个自身回合 1 次、且追加攻击不附加触电（单人时仍会触发，偏高；有队友时触电偏少）。
- 击破附带的持续伤害（灼烧/裂伤等）与纠缠/禁锢的额外延后未计；超击破只在攻击者属性为弱点时结算；易伤不设上限。
- 知更鸟【协奏】附加伤害按 dmgType=ult 记账（会吃到“终结技增伤”类效果，当前参考队伍中无此类效果）。
- 条件/层数类效果默认满足（如「于夜色中」按满 6 层、「停转的萨尔索图」按暴击率达标），部分有阈值分档的套装只取第一档（格拉默 12%、海隅 12%）。
- 只有 3 轮 350 AV：阮•梅【残梅绽】会延长击破，使流萤队在这么短的窗口里只击破 1 次，击破伤害占比随之下降（长轴时情况不同）。
- 转化类 Buff（如“提高等同于某属性 X%”）在挂上时按施放者面板快照。
- 无能量终结技（专属资源）的角色若无手写机制，按每 3 回合放一次近似（`policy.customUltEvery`）。
- “伤害倍率提高”、“基础概率”、减速、抵抗降低等描述未建模；描述为空的子技能（黄泉、乱破、银狼LV.999 部分变体）只有参数没有伤害段。
- 欢愉四人与 v1 同配置对比总伤约为 v1 的 2.2 倍（同一量级）：开场行动时机、技能等级、4.6.51 行迹数值和搜索排轴不同，详见 [engine2/overrides/README.md](../engine2/overrides/README.md)。

v2.2 数学核对后的主要变化：流萤强化战技改走通用结算（v2.1 不削韧、不触发超击破/协奏，搜索只会用强化普攻）；
阮•梅【残梅绽】改用引擎触发器（会延长击破）；持续伤害不再暴击；副词条统一为中档；击破类伤害的 vuln_break 不再重复计算；
知更鸟开场行动提前、战技 +5 能量、「即兴装饰」暴伤（原为全队常驻通用暴伤）三处重复计算已去除；搜索启发式在最后一轮内把战技点/能量价值衰减到 0。
流萤队知更鸟占比 33%：协奏期间每次队友攻击都触发 1 次 120% 攻击力、固定 100% 暴击 / 150% 暴伤的附加伤害（3 轮约 10 次，每次 1.2～2 万），属机制本身；v2.1 的 43% 主要是流萤强化战技漏算所致。

## 六、复现

    bash scripts/v2/fetch_all.sh        # 抓取原始数据 → data/v2/raw/
    node scripts/v2/build_kits.mjs      # 解析 → data/v2/kits.json、engine2/data.gen.js、PARSE_REPORT.md
    node scripts/v2/build.mjs           # 打包 → dist/hsr-sim-v2.{html,mjs,bundle.js}
    node --test tests/v2/               # 全部测试（含 math.test.mjs 数学核对）
