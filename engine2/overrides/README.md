# engine2/overrides —— 手写角色机制

自动解析（data/v2 → kit）覆盖不了的专属资源、强化形态、独立行动单位在这里手写。API 见 `../OVERRIDE_API.md`（v2.1.2），
仍缺的能力见 `API_REQUESTS.md`。每个角色一个文件 `<id>_<name>.js`（导出 `override = { name, patchKit, hooks }`），在 `index.js` 注册。

共用：
- `_util.js`：按 id 找技能、删自动解析的错误效果、按等级取 params、composeHooks。
- `_elation.js`：欢愉命途共用机制（笑点 `shared.joke`、好活当赏 `custom.gr/grT`、命途升格 `shared.upg`、阿哈时刻计时单位）。
  阿哈时刻由队内**第一名欢愉角色**用 `api.addTimer` 创建（速度 = 阿哈面板速度或 80 + 队伍速度降序 /5 /10 /20 /40，与 v1 同式）；
  到点时各欢愉角色依次施放欢愉技 → 全员获得好活当赏 = 本次计入笑点（2 回合，真珠无限）→ 清空笑点。时间轴 action = `AHA`（计入各施放者）。

## 欢愉四人 vs v1

同配置（E0、无光锥、无遗器、敌人 80 级、抗性 0、必暴；v1 = engine/sim.js defaultConfig 去掉光锥/遗器）：

| | v1 | v2 (+override) | v2/v1 |
|---|---:|---:|---:|
| 总伤 | 1,300,913 | ≈2,820,000 | ≈2.2 |
| 1506 银狼LV.999 | 281,377 | ≈1,350,000 | ≈4.8 |
| 1501 火花 | 699,994 | ≈905,000 | ≈1.3 |
| 1503 真珠 | 29,117 | ≈42,000 | ≈1.4 |
| 1511 星神★阿哈 | 290,425 | ≈520,000 | ≈1.8 |

同一量级（测试断言总伤比 ∈ [1/3, 3]）。主要偏差：
1. v1 开场全员在 AV 0 行动；v2 首回合在 10000/速度。v2 首次阿哈时刻（AV≈71）后银狼即达 60 隐藏分（秘技 20 笑点 + 回放 15 + 真结局 40），比 v1 多 1 次终结技 / 3 次强化普攻 → 银狼偏差最大。
2. v1 按最高技能等级倍率（银狼强化普攻 3.36），v2 用数据默认等级（10 级：2.4）。
3. 阿哈行迹「盒中蕴藏的世界」v2 按 4.6.51 数据（速度 ≥125/150 → 欢愉度 +120%/150%），v1 为 +20%/50%。
4. v2 轴由 beam search 选（v1 为固定"完美轴"优先级）。
5. v1 E1 火花在终结技时也加 5 笑点（v1 实现细节），v2 按描述只在阿哈时刻结束时加。

默认配置（推荐遗器/光锥、95 级敌人、期望暴击）下欢愉四人 v2 ≈ 25M（无 override ≈ 0.63M）。
注意：默认遗器下「闪耀功勋的魔法少女(4)」无视防御效果 ×10 层叠加到 >100%，属自动解析问题（非 override 范围）。
